# Code de conduite

## Principe

On contribue en livrant du travail.

## Règles

1. Une contribution est un bloc de code ou un module concret. Rien d'autre n'est une contribution.

2. On propose ce qu'on juge bon et utile, et on en explique les choix dans le code et son message de livraison.

3. Un désaccord se livre : il prend la forme d'une contre-proposition — code ou module. Aucun désaccord parlé n'est recevable.

4. Rien ne se tranche par la parole. Un commentaire n'engage à rien ; seul le travail livré, utile et retenu, fait foi.
